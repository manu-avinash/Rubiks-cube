Rubik's Cube

Rubik's Cube is a 3D combination puzzle invented in 1974 by Ernő Rubik. A standard 3x3x3 cube has center pieces (1 tile, stationary), edge pieces (2 tiles), and corner pieces (3 tiles). Every face of the cube can be rotated a full turn. There are over 43 quintillion possible moves exist, with only a single solved state. with 9 sqaures on each faces.

What's this ?

This is an image model, Binary classifier. Classifing the state of a 3 X 3 X 3 Rubik's Cube, whether it is in solved state or is it scrambled. It is been trained on a custom dataset containing around 250 solved and scrambled images of the cube on a white background with a generic mobile camera. It is fine-tuned over the imagenet model 'MobileNetV2'. Built using Keras API and opencv in python. For futher depth about the project goto Rubik's cube | GitHub an fun, full pipeline project.
